# 设计规范与 Design Tokens

## 视觉基调

- **气质与意象**：清晨的医疗实验室，阳光透过落地窗洒在浅绿色墙面，空气中有清新与秩序感。简洁、专业、温和。
- **视觉策略**：扁平化，大圆角卡片，柔和阴影，避免强烈对比与硬朗线条。

## Design Tokens

### 色彩

| 用途 | 值 |
|------|-----|
| 主背景色 | `#dce8d0`（浅薄荷绿纯色） |
| 卡片背景 | `#ffffff` |
| BU 卡片顶部条带 | `#a8d5a2` |
| 主按钮色 | `#4a7c59`（深绿，导出按钮等） |
| 文字主色 | `#2d3b2d` |
| 文字次色 | `#6b7c6b` |
| 边框色 | `#e0e8dc` |
| 警告色 | `#e74c3c`（OEE<0.9 红框） |
| 提醒色 | `#f39c12`（损耗系数/漏填黄点） |
| 展开行背景 | `#f0f7ec` |

### 字体

- 字体族：`Inter, -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`
- 标题 18-20px / 600；正文 14px / 400-500；辅助 12px / 400

### 间距与阴影

- 卡片圆角 16-20px；内边距 20-24px；卡片间距 16-20px；表格行高 48-56px
- 卡片阴影 `0 2px 8px rgba(0,0,0,.06)`；悬停 `0 4px 12px rgba(0,0,0,.1)`
- 过渡 `0.2s ease`；展开动画 `0.3s ease-in-out`

## 布局

- 最大宽度 1400px 居中；BU 卡片 4 列等宽 grid gap 16；表格全宽固定表头

## 设计禁忌

- 不要深色背景或强烈对比
- 不要硬直角（所有元素圆角）
- 不要蓝色/紫色等非绿色系主色
- 不要过于饱和的颜色、复杂渐变

## 落地方式

落地为项目根目录 `DESIGN.md`（中文章节），只写真实用到的维度，增量维护，删除被废弃的条目；样式改动前先读。
